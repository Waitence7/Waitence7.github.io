Yummi는
LoL Discord 서버를 위한 올인원 도구입니다.

전적 조회, Riot 프로필, 모집·내전 운영, 대회 관리, 그리고 Windows 로컬 League Client와 연동되는 LCU Agent까지 하나의 흐름으로 연결하는 Yummi 프로젝트입니다.

Features

Discord에서 시작해 웹과 LCU까지

기능을 따로 분리하기보다 Discord의 모집과 전적 흐름을 중심으로 웹 관리 기능과 League Client 연동을 연결합니다.

🔎

Riot ID, 현재·최대 티어, 최근 경기, 숙련도와 포지션 정보를 한 번에 조회합니다.

팀 배정 · 밸런싱

티어, 포지션, 저장된 참가자 정보를 바탕으로 팀을 배정하고 웹에서 수동 조정과 결과 관리를 이어갑니다.

🏆

대회 · 기록

참가 신청, 체크인, 팀과 시드, 대진, 경기 결과와 라이브 운영 기록을 웹에서 관리합니다.

🎮

LCU Agent

Windows PC에서 League Client와 연결해 로비·파티 상태, 참가자 초대와 일부 클라이언트 작업을 이어줍니다.

Architecture

한 프로젝트 안에서 연결되는 구조

Discord와 브라우저가 사용자 접점이 되고, Bot/Web/API가 공유 상태를 처리하며 LCU Agent는 사용자의 PC에서 로컬 League Client와 연결됩니다.

Discord / Browser사용자 입력과 실시간 UI
Yummi Bot / Web모집·전적·내전·대회 UX
API / Redis / DB공유 상태와 영속 데이터
LCU Relay ↔ Agent로컬 League Client 연동
PythonTypeScriptRustTauriPostgreSQLRedisDiscord APIRiot API / LCU

Yummi는 계속 확장 중입니다.

Bot, Web, API, LCU Agent를 하나의 프로젝트에서 함께 개발하고 있습니다. 최신 구현과 변경 이력은 GitHub 저장소에서 확인할 수 있습니다.
