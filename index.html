Yummi

Public project description and Riot API usage information

Project status: Active development
Source repository: Private
Primary platform: Discord + Web
Game: League of Legends

Project overview

Yummi is a League of Legends community tool built around a Discord bot and a companion web service. It helps Discord communities look up player information, view match history, manage recruitment for ranked games and custom matches, organize in-house games and tournaments, and connect selected workflows to the local League Client through a separate LCU agent.

This page is intentionally public so the project and its Riot API use can be reviewed even though the main source repository is private.

How the Riot API is used

Account lookupResolve Riot ID information and associate a player with a stable Riot account identifier.
Rank informationDisplay current ranked information and keep player profile data up to date.
Match historyRetrieve recent League of Legends matches for user-requested match history and profile summaries.
Champion masteryShow champion mastery information as part of player profile commands.
Server featuresUse Riot data to support player profiles, team balancing, recruitment context, and in-house match management.

Main user-facing features

  • Discord commands for player profile, rank, match history, mastery, position, and refresh operations.
  • Recruitment for ranked queue, ARAM-style modes, and 5v5 custom matches.
  • Web-based in-house match management, participant management, team balancing, match records, and tournament operation.
  • Optional LCU Agent for workflows that require access to the user's local League Client. Riot API credentials are not exposed to users.

Technical structure

The service is composed of a Discord bot, web frontend/BFF, API service, PostgreSQL database, Redis, and an optional local LCU Agent. The backend communicates with Riot services when a feature requires Riot data, and the resulting data is presented through Discord or the web interface.

Data handling

  • Riot API keys are stored only on backend infrastructure and are not sent to Discord users or browsers.
  • Player records are associated with Riot account identifiers rather than relying only on changeable display names.
  • The LCU Agent communicates with the local League Client for explicitly supported client-side features; it is separate from Riot Web API authentication.
