Yummi Feature Summary

This repository contains a Discord bot primarily designed for League of Legends stats/nickname management, recruitment posts, and message pinning.

1. Key Features

1.1 League of Legends Info Lookup

  • /info: Displays summoner tier (Solo/Flex), level, and top champion mastery information.
  • /mastery: Shows the champion mastery list and top data for a user or a specific LoL nickname using a paginated UI.
  • /rotation: Generates and sends an image of the current week's free champion rotation.

1.2 Nickname Management

  • /set_nickname: Registers a Riot nickname and saves it to the database.
  • /delete_nickname: Deletes your own registered nickname.
  • /nickname: Look up your own or another user's registered LoL nickname.
  • /secret_nick: Sends the lookup result as an ephemeral message (visible only to you).
  • /vc_nicknames: Checks the registered nicknames of all members currently in the voice channel at once.

1.3 Chat & Recruitment Helper

  • /aram: Generates a recruitment message for ARAM game members.
  • Recruitment messages include interactive buttons for Join, Reserve, Cancel Join, Cancel Recruitment, and Bump.

1.4 Message Pinning

  • !pin: A feature that pins a replied message and "bumps" it by sending a copy as a new message.
  • !unpin: Disables the pinned status of a message.
  • The pinning feature copies the original message content, embeds, and buttons to maintain a pinned replica.

1.5 Admin & Backup

  • Bot Lock (/bot_lock): Allows administrators to lock or unlock bot usage.
  • reload, reloadall: Admin-only commands to reload bot extension modules.
  • The log and backup module backs up the DB to an Excel file every hour and records member counts per server.

2. Core Data Storage

  • nicknames table: Discord User ID, Riot Nickname, Tier, and Last Update Time.
  • teams table: Server ID, Team Name, Leader ID, Member List (JSON), Team Status, Creation Time, and Voice Channel ID.

3. Requirements

  • Python 3.x
  • discord.py and related extensions
  • aiohttp, Pillow, openpyxl, python-dotenv, etc.
  • Environment variables such as DISCORD_TOKEN, RIOT_API_KEY, ADMIN_ID, and ALLOWED_GUILD_IDS must be configured in a .env file.

4. How to Run

Run the bot using python main.py.

main.py initializes the bot and automatically loads modules from directories.
